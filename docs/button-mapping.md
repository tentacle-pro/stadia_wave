# 按键映射设计

本文记录下一阶段的产品交互、执行规则与验收条件。首版已实现页面、配置保存和 macOS 执行引擎，默认参数待实物测试调整。

## 页面与编辑流程

沿用 Companion 的淡绿色、乳白色和现有导航。左侧为大幅正面手柄底图，右侧为映射列表。复用已校正的手柄素材，肩键和扳机在图片上方补充可点击热点。

点击手柄热点或右侧列表行，双向同步选中状态。仅绘制当前选中输入到对应行的连线。实际操作手柄时高亮对应部件，保持当前编辑项。摇杆的推动和按下分别配置，十字键四个方向分别配置。

选中一行后在右侧展开编辑区域，显示输入名称、动作类型和参数。快捷键通过「录制快捷键」捕获 Mac 键盘输入，显示修饰键和普通键，支持清除。录制期间暂停手柄桌面映射，结束、取消或离开页面后恢复。保留已有语音录音和草稿处理流程。

页面提供映射总开关、恢复默认预设、保存和放弃修改。按键和参数修改先保存在界面草稿，点击保存后统一生效。总开关立即保存并生效，草稿存在时继续暂停桌面输出。切换页面时提示处理未保存修改。恢复默认也须保存后生效。

## 动作类型

| 动作 | 配置内容 | 执行方式 |
| --- | --- | --- |
| 快捷键 | 修饰键和一个普通键 | 每次按下执行一次，完整按下并释放 |
| 保持按键 | 鼠标键或键盘键与修饰键 | 按住手柄输入期间保持，松开释放 |
| 临时映射 | 进入动作、保持键、临时按键映射、退出动作 | 按住指定键期间激活，松开收尾 |
| 指针移动 | 摇杆、速度、死区和响应曲线 | 按摇杆方向持续移动 |
| 滚动 | 摇杆、速度和方向 | 按偏移量持续滚动 |
| 移动与滚动速度调节 | 扳机与倍率 | 按扳机深度同时调节指针和滚动速度 |

首版快捷键默认单次触发。方向键在应用切换模式下支持按住重复，参数采用统一默认值，后续根据测试决定是否开放编辑。

## 建议默认预设

以下为首版候选预设，用户可以修改。

| 输入 | 动作 |
| --- | --- |
| Assistant | 按住录音、松开转写 |
| X / Y | 鼠标左键 / 右键，按住保持、松开释放 |
| A / B | 普通状态 Enter / Escape，有待处理草稿时确认粘贴 / 丢弃 |
| 十字键左 / 右 | Control + 左 / 右，切换桌面空间 |
| L1 | 按住进入应用切换模式 |
| 左摇杆推动 | 移动鼠标指针 |
| 右摇杆推动 | 垂直和水平滚动 |
| R1、L3、R3 | 默认留空，可自定义 |
| L2 | 同时增加指针和滚动速度 |
| R2 | 同时降低指针和滚动速度 |

未设置的输入默认无桌面动作。A、B 在没有草稿时可以配置普通映射。Assistant 及草稿确认键在界面明确标注语音用途。

## 应用切换模式

按下 L1 时，先按下 Command，再按下和释放 Tab，保持 Command。期间十字键左右分别发送左右方向键。松开 L1 后释放 Command，由 macOS 确认所选应用。

期间十字键下发送 Escape，取消切换并立即释放本模式持有的按键。L1 松开前保持取消状态，再次按下 L1 才重新进入。临时映射优先于这些输入的普通映射。

按下 L1 后直接松开也会完成一次应用切换。录制快捷键、关闭映射、失去连接、切换所有者、手柄离线、睡眠或退出时，取消模式并释放持有的键。

macOS 支持保持 Command 后用方向键选择应用，释放 Command 确认。桌面空间使用 Control 和左右方向键，实际效果受用户系统快捷键设置影响。[应用切换](https://support.apple.com/en-mk/guide/mac-help/mchlp2469/mac) · [桌面空间](https://support.apple.com/en-sg/guide/mac-help/-mh14112/mac)

## 指针与滚动

左摇杆使用径向死区，消除中心漂移。将死区以外的幅度重新归一化，以非线性曲线转换为速度，中心附近提供精细控制，外圈提高速度。斜向移动按向量长度归一化。

候选初值为死区 0.15、响应指数 1.8、最大速度 900 逻辑点每秒。移动量按单调时钟的实际帧间隔计算，唤醒后重置计时，避免累计位移跳跃。页面提供速度与死区调整，以及显示模拟指针的测试区域。

L2 使倍率从 1 连续提高至 3。R2 使倍率从 1 连续降低至 0.2。倍率同时作用于左摇杆指针和右摇杆滚动。两者同时按下时，R2 优先，暂停 L2 的加速效果。摇杆回中、停止收到有效输入或失去连接时停止移动。

右摇杆默认推动方向与内容滚动方向一致，提供反向选项。使用独立死区和速度参数，保留小数位移累计量。切换模式或断连时清空累计量。

## 语音与映射的优先级

有待处理草稿时，A、B 的事件完整交给语音流程，一次按压只产生一个结果。处理完成后的松开事件也由原操作消费。

录音期间 Assistant 保持录音语义。出现草稿时取消临时模式和已保持的鼠标键、键盘键，避免 Command 等影响确认粘贴。普通映射在语音操作释放后恢复。

映射配置不抢占目标应用焦点。用户进入快捷键录制或指针测试时暂停真实桌面输出，测试区内仅模拟位移。

## 技术实现

执行引擎位于 Companion，Bridge 继续转发手柄状态。使用现有辅助功能授权和 macOS 事件注入层，配置保存在 Companion 本地，跨 Bridge 重连复用。

新增独立映射模块处理配置、输入状态、临时模式与输出状态。按键使用按下、松开的边沿驱动。模拟量保存最新快照，由固定频率循环产生位移，按实际时间计算速度。

所有按键和鼠标保持动作记录所属控制器和映射动作。多个动作持有同一输出键时维护引用计数，最后一个持有者释放时发送抬起事件。普通快捷键与已保持修饰键的组合需统一协调，避免相互提前释放。

连接中断、接管、停止映射、修改配置、进入编辑录制、睡眠和退出都调用同一释放流程。恢复连接后等待手柄输入回到中立状态再启用，避免仍按住的键意外启动动作。停止接收状态时暂停输出，复用连接心跳与手柄在线状态判定。

配置包含版本字段。首次使用加载默认预设，读取旧版配置补全新增字段。无效配置保留原文件并提示恢复，保存使用临时文件和原子替换。权限未获准时显示授权入口，保留用户配置。

## 开发顺序与验收

1. 实现配置模型、大图热点、映射列表、快捷键录制及保存。重启后恢复，编辑期间无真实桌面输出。
2. 接入普通快捷键与保持动作。验证切换桌面空间、鼠标按住拖拽和松开释放。
3. 接入 L1 应用切换模式。验证左右选择、松开确认、取消，以及模式退出后普通十字键恢复。
4. 接入摇杆指针、滚动与扳机倍率。验证回中静止、斜向速度、加减速同时触发和睡眠恢复。
5. 验证语音共存和异常释放。在持有 Command 或拖拽时断网、关闭手柄、切换 Companion 和退出，确认输出按键释放。草稿 A / B 只执行一次语音动作。

首轮实物验收重点观察中心漂移、指针速度、滚动方向、应用切换按住重复，以及语音流程与临时模式切换时的冲突。


## 首版实现与测试记录

映射默认关闭。页面总开关使用 NSH Switch，切换后立即保存并生效。按键和参数编辑仍需点击保存。配置位于 Companion 数据目录的 button-mapping.json，损坏或不支持的版本会显示恢复提示。快捷键通过聚焦的 NSH 自定义视图捕获，录制时暂停真实桌面输出。测试指针时仅在页面内预览。恢复预设同样保持关闭，需保存后生效。

当前提供内置应用切换模式，方向键左右选择、向下取消。进入与退出动作以及模式内映射采用这套固定预设。任意自定义临时模式编辑器留待后续扩展。已实测 Companion 完全退出后，其启动的 Bridge 进程随之结束，重新打开后可恢复配置并启动本机服务。

自动回归已覆盖 Command 保持、松开确认、取消、多个映射共用修饰键、异常释放与恢复前等待中立，以及摇杆径向死区和斜向速度。原生窗口已验证组合键录制、保存后重新读取与未保存修改导航保护。实物已通过 L1 应用选择、松开确认、取消，十字键切换桌面，摇杆移动与回中停止，扳机加减速、R1 拖拽、右摇杆滚动，以及映射开启后的语音 A 确认一次、B 丢弃。系统桌面切换需在方向键事件中携带 macOS 的 secondary Fn 标志，修复后已复测通过。断连释放已通过执行引擎回归测试，物理断网时持续按住按键的场景仍待专项实测。

鼠标布局更新采用配置版本 2。旧版完整默认预设自动迁移为 X 左键、Y 右键、A Enter、B Escape，并释放 R1。旧版自定义映射逐项保持原值，用户可通过恢复预设采用新布局。左右鼠标键分别记录保持状态，语音草稿出现和异常释放时同时清理。

本轮实物复测已通过 X 点击与拖拽、Y 右键菜单、普通状态 A 回车与 B 关闭菜单，以及右摇杆滚动时 L2 加速和 R2 减速。Switch 的即时生效与配置保存已在原生窗口验证。
